# Casos reales — guía para el equipo

La web incluye una sección **Recent work** (`#work`) con casos basados en tipos de evento que ya hacéis. **Sustituid nombres de cliente** cuando tengáis permiso.

## Cómo añadir un caso nuevo

1. Editar `src/content/en.ts` → bloque `caseStudies.items`.  
2. Campos: `type`, `title`, `location`, `format`, `body` (2–3 frases), opcional `highlight`.  
3. Si hay foto real: `public/images/cases/nombre.jpg` y campo `image`.  
4. Pedir **permiso por escrito** para logo, nombre de marca o fotos con invitados.

## Checklist por caso (para vosotros)

- [ ] Tipo de experience (wine / team / showroom / fair / gala / brand)  
- [ ] Ciudad + país (ej. Barcelona, Suiza)  
- [ ] Formación real (solo, dúo, trío, banda)  
- [ ] Nº invitados aproximado  
- [ ] Qué funcionó (volumen, timing, reveal, internacional…)  
- [ ] ¿Podemos nombrar al cliente? (sí / solo sector / no)  
- [ ] Foto usable (sí / pendiente)

## Casos que conviene documentar pronto

1. **Suiza** — off-site o cena corporativa internacional.  
2. **Showroom / demo sonido** — marca audio o automoción.  
3. **Feria / exposición** — stand o zona networking.  
4. **Congreso** — coffee break o welcome.  
5. **Cata / bodega** — si existe en portfolio.  
6. **Gala / premios** — hotel o asociación.

Enviad bullets por WhatsApp/email interno y los volcamos a la web en inglés (y español cuando exista `es.ts`).
